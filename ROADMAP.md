# RMPCS roadmap

The current build is v0.8.0: Rusty's PC Toolkit, adding original recommendations 6 (crash/stability reports), 7 (verified restore-point requests and app-preference undo), 10 (network diagnostics/comparisons), and 12 (opt-in bounded workload deferral/start windows).

Existing before/after run summaries, local log archives, opt-in completion notices, Settings, Help, updates, graphical setup and maintenance safeguards remain available. See README and release notes for scope and validation limits.

## Next priorities

1. Supervised clean-machine, missing-runtime, upgrade and uninstall testing.
2. Native restore-point availability, frequency-limit, verification and failure testing without changing protection policies.
3. Windows scheduling validation across real games/calls/downloads, idle/power transitions, multiple adapters, timezone/DST changes and scheduled-to-tray delivery.
4. Installed same-user/admin undo validation and broader integration coverage for reports and archive destinations.
5. Drive-health/filesystem checks and supported Windows component cleanup.
6. Broader startup coverage with explicit Windows approval/startup-folder handling.
7. Degenerates Inc. artwork and LootDrop-inspired visual styling.

Build and isolated checks do not replace live Windows validation. No performance or repair-success guarantee is made.
