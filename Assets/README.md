# RMPCS icon pack

Original shield, crown and pulse artwork for the RMPCS PC toolkit, created for Degenerates Inc.

- `RMPCS.ico`: transparent Windows icon with 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel frames. Used by the app executable, taskbar, tray, setup executable, desktop and Start Menu shortcuts, and Installed apps entry.
- `RMPCS.png`: high resolution transparent artwork for app headers and future branding.
- `Export-Icons.ps1`: reproducible ICO export from the PNG using Windows System.Drawing. Export only; no installation or settings changes.

Installed shortcuts receive their icons automatically. For a manually created portable shortcut, choose Properties > Change Icon and select `RMPCS.ico` from the extracted portable folder. Keep the portable files together.
