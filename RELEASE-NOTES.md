RMPCS v0.12.0 - Rusty's PC Toolkit

Six new coordinated themes and five new bundled font families, selected in Settings > Fonts & appearance.

Themes: Ocean Slate, Nordic Frost, Forest Mist, Warm Sand, Rose Quartz and Graphite. Each includes Light/Dark backgrounds, cards, readable body/secondary text, input outlines, hover/selection colors and switches. System mode follows Windows. The original eight accent presets and custom HEX/RGB behavior remain available, and High Contrast overrides custom colors. There are now 14 presets.

Fonts: Lato, Poppins, Hind, PT Sans and Oxygen. These join Barlow, Rajdhani and Atkinson Hyperlegible, with Windows system still available. Regular and SemiBold/Bold faces are embedded in the app; no font installation or runtime download is needed. All eight families retain their copyright/OFL license texts in installer and portable distributions; the source bundle includes original files and pinned upstream hashes.

Appearance preview, Save appearance, Discard preview, preference reset and undo support all new choices. The theme selector is now labeled Theme palette to reflect coordinated surface colors. Maintenance, startup entries, scheduling, permissions and network behavior are unchanged.

Validation includes core preference/contrast tests, all 14 Light/Dark WPF theme applications, packaged font-face/license resolution, preview/discard and Back navigation, sidebar lifecycle checks and distribution/payload integrity. Visual samples cover all new palettes and fonts across desktop, compact and sidebar layouts. No real maintenance, font installation, app installation/upgrade/uninstall or runtime installation was performed. Live Windows High Contrast/accessibility transitions and broad beta validation remain necessary.

Installer EXE, standalone MSI, portable ZIP, source bundle, icons, runtime links and SHA256SUMS.txt are included. Exit RMPCS from the tray before upgrading. Discord announces the release after all required files finish uploading.

Unsigned development prerelease.
