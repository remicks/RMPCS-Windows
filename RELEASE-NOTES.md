RMPCS v0.9.1 - Rusty's PC Toolkit

A calmer UI with guided choices, theme-aware switches and complete app appearance support. This patch supersedes v0.9.0 and restricts app native-library resolution to Windows System32, including dark-title-bar integration. App-folder DLLs are not considered for native imports.

- Guided Overview: Check my PC, Review recommended care and Manage startup apps. Recommended care now opens the task review rather than starting it. Run selected tasks appears only in Maintenance. Advanced tools and raw startup-entry details are expandable. Results use a clearer shared panel; the window fits smaller work areas.
- Startup-entry toggles replace separate disable/restore buttons. On means a Run entry is present; Off means a saved RMPCS-disabled entry. Windows/Task Manager may still block an entry. Changes require administrator rights and explicit confirmation and keep existing protected-backup, snapshot and conflict checks. Loading/refreshing does not write. Cancel/denial resets the switch; a failed operation refreshes the inventory instead of claiming success. Stored commands are never executed.
- Restrained switches for preferences, administrator prompting, RMPCS sign-in startup, scheduled maintenance and idle/AC conditions. General preferences require Save; administrator prompting uses Apply. Startup/schedule switches ask for confirmation. Unknown task state disables switches. Maintenance selections remain checkboxes, followed by the existing run confirmation.
- Whole-app appearance: System, Light and Dark; eight LootDrop-inspired accents (Midnight Purple, Electric Blue, Neon Cyan, Emerald Green, Crimson Red, Sunset Orange, Hot Pink, Gold); custom HEX/RGB. Midnight Purple uses #D58AFF and a related dark palette. Preview is immediate. Save appearance preserves only the look; Save preferences saves all general settings; Discard preview restores the saved look. Views, controls, dropdowns, results, grids, switches, confirmations and tray menus share dynamic theme resources. High Contrast takes priority; System mode observes Windows changes. Accent text/labels select contrasting colors; focus and On/Off state remain visible. OS-owned file/UAC dialogs and installer surfaces retain their OS/installer styling.
- App-owned confirmations use the current theme and default to Cancel. Closing or escaping a Yes/No confirmation never approves it. Appearance choices participate in existing preference undo and normalization.

No theme downloads, external executable theme files, new dependencies, additional maintenance commands or altered deletion/repair rules. Themes do not change Windows personalization. Installer packaging retains the verified single embedded cabinet.

Validation covers theme input validation/normalization, HEX/RGB conversion, accent contrast in light/dark, persistence/undo, startup switch denial/cancellation/direction/failure, existing maintenance/update/archive checks, live WPF resource changes and switch templates, review-without-run behavior and confirmation defaults. UI previews use artificial startup fixtures; real startup entries were not changed. MSI extraction/payload verification and both launcher self-tests remain required.

Download RMPCS.Setup.exe or the portable ZIP (extract all files, then open Launch-RMPCS.exe). Standalone MSI, source/full bundle, icon pack, RUNTIMES.md with official Microsoft links and SHA256SUMS.txt are included. Exit the tray app before upgrading.

Unsigned development prerelease. Actual elevated startup/task changes, high-contrast/system-theme changes under real Windows sessions, assistive-technology use, multi-monitor/DPI transitions and installation/upgrade/uninstall still need supervised validation. Existing restore-point and workload-detection limitations remain documented in Help. Passing checks does not prove zero risk.
