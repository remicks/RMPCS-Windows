RMPCS v0.8.0 - Rusty's PC Toolkit

Original recommendations 6, 7, 10 and 12:

6. Crash/stability reports: new Diagnostics tab with 1/7/30-day System/Application metadata samples, recurring source/ID counts and explicit report export. No raw event messages or machine/user identifiers collected. Counts do not establish a cause or prove stability.
7. Restore points and reversible settings: new Protection tab creates and verifies a fresh matching Windows restore point. Accepted-but-skipped requests never report success. Optional pre-repair requests in Settings apply only to manual DISM/SFC/Search resets; unverified requests require a default-No confirmation before continuing. No System Protection, service or frequency changes, automatic OS rollback or claim that restore points recover deleted personal files. One-step undo covers app preferences and the installed administrator-prompt choice, with state-conflict checks and same-identity checks for administrator undo. Existing startup-entry restore remains available. Cleanup, repairs and schedules are not undone.
10. Network diagnostics before repair: fixed-host DNS/HTTPS HEAD plus five gateway ICMP probes, conservative advice and in-memory before/after comparisons for the same target/gateway. Explicit report exports can retain results. Normal TLS checks, no account credentials, cookies, redirects or automatic resets. Gateway latency is not Internet latency; multiple gateways/ICMP filtering and natural variation are explained. Reports may contain private gateway addresses; review before sharing. Nothing is uploaded.
12. Smarter scheduling: opt-in 1/2/4-hour start windows and bounded 15/30/60-minute workload waits. CPU/RAM/traffic, full-screen/presentation/quiet signals and microphone-session activity defer starts; unknown signals defer conservatively. No audio recording or process termination. Selected idle/AC conditions are rechecked after waiting. Windows are local-time start restrictions, not limits that kill an active repair. Skips are logged and can use the existing opt-in tray notice. Game/call/download detection is best effort. Defaults preserve existing schedules until explicitly saved.

New Diagnostics and Protection sections keep manual checks inside RMPCS. Explicit text export verifies a new local destination through its held file handle and refuses overwrite/linked folders. Original file-age, root, link/hard-link, UAC, repair ordering, renewal and restart safeguards remain in place. No new runtime or package dependency. Installer authoring now explicitly produces one embedded cabinet without the legacy media-size split; complete extraction and payload hashes are verified before publication.

Download RMPCS.Setup.exe for guided installation, or extract the portable ZIP and open Launch-RMPCS.exe. Standalone MSI, portable/source ZIPs, icon pack, RUNTIMES.md with official Microsoft links and SHA256SUMS.txt are included. Exit the tray app before updating.

Validation: isolated workflow and safety tests cover strict scheduled argument parsing, day/midnight/window edges, XML safeguards, load thresholds, unknown signals, idle/AC rechecks, restore verification rules, preference undo/conflicts/size limits, metadata-only report formatting and network comparisons. Existing file/archive/update tests, MSI verification and both bootstrap self-tests remain required. UI sections are rendered for review, and a read-only native diagnostics/probe check stores only validation status. No actual restore point, runtime installation, cleanup, registry preference change or scheduled task was created during development.

Unsigned development prerelease. Live restore creation on enabled/disabled/frequency-limited Windows configurations, real game/call/download detection, idle/power changes during scheduled deferral, preference undo in an elevated installed session and installation/upgrade/uninstall still need supervised Windows validation. Passing checks does not prove zero risk.
