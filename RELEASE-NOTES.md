RMPCS v0.10.1 - Rusty's PC Toolkit

A compact sidebar keeps RMPCS tools close at hand without occupying a full desktop window. This build also refreshes the reservation status correctly after mode changes and a successful retry.

- Choose Sidebar in the main header for a single-pane view with a page picker, Results & activity, tray access and a quick Full window button. Every existing page, task confirmation and administrator check is retained. Health checks, cleanup previews and maintenance display their output in the results pane.
- Settings > Sidebar provides Left/Right docking, current or selected display, and 360/400/440/480 scaled-unit widths. Apply sidebar settings saves only sidebar preferences; the main Save preferences button includes them too. Sidebar mode and reservation are off by default. Themes and switches follow the rest of the app.
- Optional Reserve desktop space while visible uses Windows appbar registration so maximized ordinary apps leave room. Hiding, minimizing, leaving sidebar mode or exiting releases the reservation. Reopening reacquires it; hidden sign-in startup reserves no space. The app does not change the global work-area setting, move other apps or modify taskbar settings.
- Sidebar stays above ordinary windows. Full-screen apps, other topmost windows and Windows security UI can overlap; reservation is not a security boundary. Appbar full-screen notifications yield the sidebar's z-order. If reservation is unavailable, a status explains overlay fallback.
- Monitor selection falls back visibly if a display is unavailable. Windows DPI-aware positioning preserves negative display origins, respects taskbar work area and caps width at half the monitor. Display/DPI/work-area and Explorer-restart messages update placement. Full-window mode restores previous bounds or fits them to an available display.
- Per-user sidebar settings are normalized, remain data-only and participate in interface undo/reset. Layout changes never authorize or start maintenance. Native imports remain restricted to System32. Only the two layout-only shell messages are permitted through this window's UIPI filter for unelevated Explorer callbacks; no maintenance messages or commands are added.

Validation: 193 core checks plus sidebar WPF/native placement and isolated appbar lifecycle checks across three display layouts. Tests cover all page routes, both edges, overlay work-area preservation, missing-monitor fallback, hide/minimize/restore/disposal and failed-position cleanup. Light/dark previews were reviewed. The development desktop has no Explorer appbar service; real reservation success, taskbar interaction, full-screen handoff, Explorer restart and physical mixed-DPI/hot-plug behavior need supervised Windows validation. No live maintenance, runtime installation, app installation, upgrade or removal was performed for this feature.

Download RMPCS.Setup.exe for guided installation, or use the standalone MSI if the runtime is already installed. Portable ZIP, full source bundle, icons, runtime links and SHA256SUMS.txt are included. Exit RMPCS from the tray before upgrading. GitHub publishes an automatic Discord announcement after the download set is complete.
