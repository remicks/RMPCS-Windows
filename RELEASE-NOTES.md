RMPCS v0.7.0 — Rusty's PC Toolkit

Three additions, in usefulness order:

1. Before/after run summaries. Manual and scheduled logs include duration, failure/skip status, per-category cleanup counters, and Windows OS-drive free-space observations. Logical deleted-file size, estimated Recycle Bin reduction and observed available-space change are reported separately. Other activity, compression, allocation, quota and open handles can affect free space; no repair-success or performance guarantee is inferred. The last manual summary is also shown below Activity.
2. Local diagnostic ZIP archives from History. Archive a selected saved run or the latest 30 app logs. Originals stay in place. Active, inaccessible, linked or oversized sources are skipped, with a review manifest. Limits: 30 logs, 8 MiB per file, 32 MiB total source data. Sources are validated and read through the same held handle; archive entries use fixed safe leaf names. A new local destination is verified before writing; existing files are never overwritten. Failed exports may leave an incomplete ZIP. Archives contain potentially private log text, are not encrypted and are never uploaded by RMPCS.
3. Opt-in maintenance completion/failure notices. Enable in Settings and Save. A resident tray instance in the same Windows session can show notices for manual/scheduled completion, review-needed, stopped, skipped or pending restart states. Scheduled processes send only a fixed numeric status; no strings, paths, logs, credentials or commands cross the notification boundary. Windows integrity isolation remains in force. Notices are rate-limited, best effort and informational only; History is the place to verify results. No polling, new service, new task, unattended repair category or automatic file collection is added.

Existing cleanup roots, file-age rules, link/hard-link protections, confirmations, repair sequencing, stop semantics, network-renewal safeguard and restart suppression remain in place. Native cleanup/repair commands have not been expanded. Help documents the new features.

Use RMPCS.Setup.exe for guided installation, or extract the portable ZIP and open Launch-RMPCS.exe. Installer, MSI, portable/source ZIPs, icon pack, runtime links and checksums are included. Exit the app before updating if closing hides it to the tray.

Validation covers isolated maintenance workflows, logical/estimated summary separation, unavailable/negative/overflow observations, archive exact bytes and manifest, filename/destination safety, source/count/total-byte limits, active/read-only files and notice policies. Hard-link/junction cases run where fixture creation is permitted. Existing launcher, MSI, update and GUI rendering checks are retained. No real maintenance, startup entry or scheduled task changes were performed during development.

Unsigned development prerelease. Live scheduled-to-tray delivery, Windows notification suppression/UIPI behavior, real drive observations during maintenance and elevated installation/upgrade/uninstall still need supervised Windows validation. Passing checks does not prove zero risk.
