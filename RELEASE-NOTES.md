RMPCS v0.9.2 - Rusty's PC Toolkit

Setup now stays on screen while Windows installs, upgrades or removes RMPCS, with visible progress and clearer outcomes.

- Setup EXE: a dedicated Installation page replaces the thin footer strip. It remains in the taskbar while files are prepared, integrity/trust checks run, prerequisite setup executes and Windows Installer applies the MSI. Verification runs away from the UI thread so the window stays responsive. Known-length runtime downloads show download percentage; other phases show an explicitly indeterminate activity bar. Windows Installer's separate window provides native installation progress. The launcher never invents an overall percentage or forcibly terminates the installer.
- Standalone MSI/full UI: a modeless progress dialog appears before execution for install, major upgrade, repair and removal. Its bar subscribes to native SetProgress events and its status subscribes to ActionText. Windows can pause/reset estimates or move the bar backwards during rollback. Upgrade removal of the older version remains covered by the parent operation's progress window.
- Cancellation: the MSI asks before cancelling, with Keep working as the default. Windows Installer handles rollback. The setup launcher stays open until its child process exits and prevents close/exit from killing an active installation. A cancellation received during preparation/verification is checked again before any next installer/app launch.
- Outcomes: full MSI UI has separate completion, removal, cancellation and failure screens. The setup EXE returns to its completion page only for accepted success/restart-required results. Failed/cancelled operations cannot launch RMPCS or show a successful completion page. Earlier successful prerequisite installation is not claimed to be undone.
- Windows Installed apps/basic-UI removal uses Windows Installer's built-in progress display. Explicit silent command-line installs/removals remain silent. Windows UAC and Microsoft setup/license prompts remain visible under Windows control; setup does not force itself above secure-desktop prompts or other applications.

Desktop/Start Menu/administrator choices, the optional post-install launch, runtime checksum/signature checks, verified single-cabinet payload, repair sequencing and maintenance safeguards are retained. Portable prerequisite setup receives the same progress-page improvements; its normal launch behavior is preserved.

Validation includes offline MSI dialog scheduling/subscriptions/cancellation/outcome checks, full cabinet extraction and payload hashes, launcher integrity self-tests, and isolated WinForms progress checks for phase visibility, status forwarding, prevention of close during active installation, failure/success state separation and pre-launch cancellation. Preview progress is fixture-only. No real runtime installation, app installation, upgrade or removal was performed during development.

Download RMPCS.Setup.exe for guided installation, or the standalone MSI when the runtime is present. Portable/source bundles, icons, runtime links and SHA256SUMS.txt are included. Exit the tray app before upgrading.

Unsigned development prerelease. Live elevated installation/upgrade/removal, Windows Installed apps behavior, native progress-event delivery, rollback, restart-required outcomes and high-DPI/multiple-monitor behavior still need supervised Windows validation.
